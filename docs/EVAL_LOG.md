# Sewa Setu Evaluation & Failure Log

This document tracks all evaluation runs, failures observed across persona simulations and automated test suites, root cause analyses, code/prompt fixes, and re-test verification results.

---

## Evaluation Log Format
Each logged failure records:
- **Timestamp / Run ID**
- **Persona / Test Case**
- **Model Behavior Observed**
- **Root Cause Category** (`tool description unclear` | `missing tool output field` | `validation message confusing` | `harness bug` | `portal behavior`)
- **Fix Applied**
- **Commit Reference & Outcome**
